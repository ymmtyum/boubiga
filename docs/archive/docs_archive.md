# boubiga Docs Archive

このファイルは、対応済みタスクや過去の方針変更を保管するためのアーカイブです。

最新の実装計画はルートの `boubiga_implementation_plan.md` を参照します。

## 対応済みタスク

- 最小ローカル永続化を追加し、現在端末登録、カラー、バッテリーOCR/手入力結果、使用感ログ、相場確認、診断ログ、確認待ちタスク状態を `UserDefaults` + JSON で再起動後も復元できるようにした
- 初回起動時のアプリ状態をサンプルデータ起点から、保存データまたは現在端末検出起点へ変更した
- 設定のリセット導線を「登録データを消してやり直す」に変更し、現在端末登録、バッテリー記録、使用感ログ、相場確認、診断ログ、確認待ち状態を消して初回登録へ戻るようにした
- `DeviceSnapshot` / `RemoteAppConfig` / `RuleDefinition` / `RuleEngine` と `bundled_app_config.json` を追加し、ローカルJSONで配信ルールを評価できる土台を作った
- `RuleEngine` の結果をホームのインサイト表示と診断結果に一部接続し、確認・注意・解決につながる表示を出せるようにした
- iPhone診断カードから開く簡易診断結果シートを追加し、無料結果とPro詳細診断プレビューを分けた
- StoreKit 2の `EntitlementManager` を追加し、Product ID `boubiga_pro_lifetime` の商品読み込み、購入、復元、ローカルPro判定のアプリ側土台を作った
- Paywallを追加し、非Proでは詳細診断入口からPaywallへ進めるようにした
- Apple Developer / App Store ConnectのTeam IDを `RSB2T5LYYP`、Bundle IDを `com.boubiga` に決定し、Xcode側の署名設定も合わせた
- App Store Connectで買い切りPro商品 `boubiga_pro_lifetime` を作成した
- Supabase初期DBスキーマを追加し、管理者プロフィール、設定バージョン、iOS情報、しきい値、ガイド、アクション項目、ルール、公開設定、監査ログを作成できるようにした
- Supabase RLSポリシーを追加し、管理系テーブルを `admin_profiles` のロールで制御する方針にした
- `bundled_app_config.json` と同等の初期公開JSONを投入する Supabase seed SQL を追加した
- Supabase Edge Functions の `get-published-config`、`preview-rules`、`publish-config` を追加した
- サーバー設計、管理者初期化、デプロイ順を `docs/server/supabase_design.md` に整理した
- SupabaseのIDやキーを記入する `.env.local`、共有用 `.env.example`、セットアップ手順 `docs/server/supabase_setup.md` を追加した
- Supabaseリモートプロジェクトへmigrationを適用し、Edge Functionsをデプロイし、初期管理者を `owner` として登録した
- iOSアプリに Supabase公開設定取得用の `AppConfigClient` 土台、`supabase_public_config.json`、取得結果のローカルキャッシュを追加した
- `get-published-config` を認証なし公開Functionとして再デプロイし、iOSが service role key や anon key なしで公開JSONだけを取得できるようにした
- やることリスト本体に `RuleEngine` のtodo出力を接続し、固定タスクとの重複を抑えるようにした
- `VersionNumber` を追加し、iOS最新判定を配信JSONの `latest_global_version` と安全に比較できるようにした
- タブは中央（apple ネイティブ）に戻して、いったん `TabView` ベースで確認できる状態にした
- マイiPhoneホームは、現在のiPhoneを主役にして情報量を少し絞った
- 「このiPhoneを検出しました」は登録済み状態で常設カードにせず、軽いサマリー表示にした
- 登録済みのあとの検出情報は1行に近い要約表示へ圧縮した
- 現在のiPhoneをホーム最上段に置き、端末情報をそこへ寄せた

- 登録日、最終更新日などの補足情報はホームから外し、詳細画面側に残した
