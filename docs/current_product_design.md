# boubiga 現状機能・デザイン整理

最終更新: 2026-05-21

## 1. プロダクト概要

boubiga は、いま使っている iPhone の状態を軽く把握し、使いづらさの解消や買い替え判断につなげるための iPhone 特化アプリです。

主役は「あなたのiPhone」です。診断アプリとして不安を強めるのではなく、所有している iPhone の状態を写真、数値、色、短い言葉で自然に見られる体験を優先します。

## 2. 現在の画面構成

現在はタブを置かず、`マイiPhone` のホーム1画面を中心にしています。診断も別タブにはせず、ホーム最下部のカードとして扱います。

ホームの構成:

1. 左上の設定ボタン、右上のやることリストボタン
2. あなたのiPhoneカード
3. 状態メーター
4. バッテリー未確認時の誘導カード
5. 使いづらさを解消する
6. iPhone診断カード（最下部）

ホームから外しているもの:

- 診断タブ
- AirPods診断
- SIM診断
- 常設のやることリストカード
- 使用感カード
- 記録ログ
- 次の判断カード
- 過去の iPhone 一覧
- 登録日や最終更新日の常設表示

## 3. ホーム上部ボタン

ホーム左上には設定ボタン、右上にはやることリストボタンを置いています。

両方とも共通部品 `ToolbarCircleIcon` を使い、Apple の一般的な最小タップ領域に合わせて `44pt x 44pt` の円形ボタンに統一しています。

サイズ指定:

- ボタン外形: `44pt x 44pt`
- iPhone 16 Pro の `@3x` 換算: `132px x 132px`
- 内部アイコン: `23pt`
- 通知数字バッジ: `15pt x 15pt`
- バッジ文字: `9pt`

右上のやることリストボタンは、確認待ちがある場合だけ赤い数字バッジを表示します。赤いドットではなく数字を出し、件数は `9+` まで丸めます。

## 4. あなたのiPhoneカード

ホームの主役カードです。

表示するもの:

- iPhone の写真
- `あなたのiPhone`
- 機種名
- カラー名

表示しないもの:

- 登録日
- 最終更新日
- 参考買取価格
- バッテリー最大容量
- iOS バージョン
- ストレージ容量

狙いは、スペック表ではなく「自分の iPhone がここにある」感覚を作ることです。状態や数値は下のメーターに分けています。

## 5. 状態メーター

状態メーターは2カラム表示です。ホームでは説明を長くせず、アイコン、数値、状態ラベル、グラフ、短い根拠情報に絞っています。

現在のカード:

- バッテリー
- ストレージ
- 使用期間
- 参考買取価格
- iOS

各カードの右上には情報ボタンを置き、用語の意味を短く確認できます。小さなグレー文字は、アクション誘導ではなく「確認日」「出典」「使用量」などの根拠情報に寄せています。

### バッテリー

表示内容:

- 最大容量
- 状態ラベル
- 横棒グラフ
- 確認日または充放電回数

バッテリー最大容量は公開 API で直接取得できないため、設定アプリのバッテリー画面スクショを OCR して取得する方針です。

### ストレージ

表示内容:

- 空き容量
- 使用量 / 総容量
- 横棒グラフ

空き容量と総容量は現在端末のスナップショットとして扱います。以前出していた `空き 24GB/128GB` のような重複情報は整理し、レイヤーを統一しています。

### 使用期間

表示内容:

- 使用期間
- 未確認時は `未確認`
- バッテリー状態スクショから算出できることを補足

使用期限のような誤解を招く表現は使わず、「使い始めてからどれくらいか」を見るカードとして扱います。

### 参考買取価格

表示内容:

- 参考買取価格
- 出典
- 確認日

MVP では自動取得せず、ゲオ参考買取価格のテスト値または外部確認導線として扱います。

### iOS

表示内容:

- 現在の iOS バージョン
- 最新判定

現在の最新 iOS は `26.5` として判定しています。最新ではない場合、カードは黄色系の表示になり、`最新ではありません` と伝えます。

## 6. やることリスト

ホーム常設カードとしては出さず、右上のチェックボタンから開きます。

挙動:

1. まず「何をしてほしいのか」を一覧で見せる
2. 項目を選ぶと、そのアクションを促す画面へ進む

バッテリー最大容量が未確認の場合は、バッテリー容量スクショの追加タスクとして扱います。状態メーター内には `スクショで更新` ボタンを置きません。

## 7. バッテリーOCR

設定アプリの「バッテリーの状態」画面スクショから、以下の情報を読み取ります。

- 最大容量
- 充放電回数
- 製造日
- 最初の使用
- バッテリー状態
- 使い始めてからの期間

画面方針:

- 大きなスクショアップロード枠を主役にする
- 明示的に `スクショを読み取る` を押して OCR を開始する
- 読み取り結果は入力欄ではなくカードで見せる
- `修正する` を押した時だけ編集状態にする
- 最大容量が読み取れていれば保存できる
- 最大容量が読めない場合は、保存ボタンから修正状態へ進める

## 8. 使いづらさを解消する

以前の `気になるところ` を、現在は `使いづらさを解消する` に変更しています。

目的:

- 不安や欠点の羅列ではなく、使いづらさを解決する導線として見せる
- 注意が必要な項目だけを1項目1カードで表示する
- 文字サイズを大きめにし、読みやすさを優先する

表示内容:

- 見出し
- 注意項目カード
- 状態チップ
- 説明文
- `解決する` ボタン

対象になる項目:

- バッテリー
- 容量
- 使用感
- 相場

問題がない場合は、安心できる短い文章だけを表示します。

## 9. iPhone診断カード

診断タブは置かず、ホーム最下部に `iPhone診断` カードだけを置いています。

現在は入口カードとしての仮実装です。AirPods診断とSIM診断は表示していません。1画面構成のシンプルなデザインを守るため、診断領域はホーム下部に控えめに配置します。

表示内容:

- iPhone アイコン
- `iPhone診断`
- 現在の機種名を含む短い説明
- 右向きの矢印

将来的には、バッテリー、容量、使用感、買い替え意向を整理する質問導線につなげます。

## 10. オンボーディング

初回起動時は、現在端末の検出から始めます。

基本フロー:

1. iPhone 検出
2. 写真つきの機種確認
3. 写真つきのカラー選択
4. 登録完了
5. ホーム表示

検出には `iphone_identifiers.json` の端末識別子マップを使います。検出できた機種は原則確定扱いにし、`違うiPhoneを選ぶ` を押した場合だけ補助的にモデル選択を出します。

カラー選択では、全カラーを写真つきカード一覧で表示します。iPhone 16 Pro / 16 Pro Max は Apple 公式仕様に合わせ、以下の4色を表示します。

- ブラックチタニウム
- ホワイトチタニウム
- ナチュラルチタニウム
- デザートチタニウム

## 11. 詳細画面

あなたのiPhoneカードを押すと、詳細画面を開けます。

詳細画面では、ホームでは省いた情報やタスク状態を確認する文脈として扱います。端末画像はホームと同じく、選択中カラーに対応した画像を表示します。

## 12. 設定

ホーム左上の歯車ボタンから設定を開けます。

現在の項目:

- 通知設定
- データ管理
- プライバシー
- Pro機能

データ管理から `オンボーディングからやり直す` を実行できます。あなたの iPhone 登録をリセットし、初回登録フローからやり直せます。

## 13. デザイン方針

全体方針:

- 画面は iPhone の写真を主役にする
- カードは白を基調にして、淡いグリーン系の背景になじませる
- 数値、アイコン、色、グラフで状態を伝える
- 長い説明文は避け、必要な情報はシートや詳細へ逃がす
- 事務的な `未完了` 感を減らし、状態確認と軽い解決導線として見せる
- 重要な操作はカード内に詰めすぎず、やることリストや詳細画面へ分ける

文字の扱い:

- ホームの主役カードは大きめの機種名
- 状態メーターは数値を大きく、補足は小さく
- `使いづらさを解消する` は読みやすさ重視で大きめ
- 小さなグレー文字は根拠情報に限定する

色の扱い:

- 良好: グリーン系
- 注意: イエロー / オレンジ系
- 未確認: グレー系
- 価格: グリーン系
- ストレージ: ブラウン / オレンジ系

## 14. 現在の実装上の前提

- UI は SwiftUI ベース
- 主な画面実装は `boubiga/ContentView.swift`
- 表示モデルとサンプルデータは `boubiga/AppModels.swift`
- 永続化やバックエンド連携は未実装
- 現時点ではサンプルデータで体験を確認している
- 次の大きな実装優先度は最小ローカル永続化

## 15. 将来方針

将来的に運営側で管理するサーバーを開設し、以下の情報をアプリ側へ配信する方針です。

- 最新 iOS バージョンと更新内容
- iPhone や周辺機器の参考価格
- 買取価格や交換費用
- 容量削減ガイド
- バッテリー確認ガイド
- 買い替え比較ガイド
- iPhone診断の質問や説明文

MVP では、まずローカル定義やテスト値で体験を固めます。
